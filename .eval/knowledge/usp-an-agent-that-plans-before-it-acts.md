# An agent that plans before it acts

Chat with Otto is an agent that plans multi-step content tasks and shows the plan before acting, so a user can stop it before anything is produced or sent.

> "Chat with Otto is an agent that plans multi-step content tasks before it acts, which means a user sees the plan and can stop it before anything is produced."
>
> — `positioning.md`

> "Otto, the agent, must always show its plan before acting on a multi-step task."
>
> — `content-rules.md`

> "It cannot send, post or publish anything without a person confirming the plan."
>
