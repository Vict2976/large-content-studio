# Goals

_What "good" means to this company, in the order the sources gave them._

1. By 2026 a marketing team publishes twice as much with the same headcount, and the extra volume reads as if the same person wrote all of it.
   > "Our goal for 2026 is that a marketing team publishes twice as much with the same headcount, and that the extra volume reads as if the same person wrote all of it."
   >
   > — `goals-2026.md`


2. Be the tool a team opens first in the morning, so the studio is where work starts rather than where it is pasted afterwards.
   > "We want to be the tool a team opens first in the morning, so that the studio is where work starts rather than where it is pasted afterwards."
   >
   > — `goals-2026.md`


3. A draft leaves the blog writer and is published with light edits in at least four cases out of five; a rewritten draft counts as a failure to fix, not a success.
   > "Success means a draft leaves the blog writer and is published with light edits in at least four cases out of five."
   >
   > — `goals-2026.md`

   > "A draft that gets rewritten is a failure we want to see and fix, not a success we count."
   >
   > — `goals-2026.md`


4. Keep the agent trustworthy: Otto plans before it acts and every plan is shown to the user before anything runs, keeping a person in control of what gets sent.
   > "We need to keep the agent trustworthy."
   >
   > — `goals-2026.md`

   > "Otto plans before it acts, and every plan is shown to the user before anything runs, in order to keep a person in control of what gets sent."
   >
   > — `goals-2026.md`


5. Translation aims for fidelity of tone, not just words—a translated caption should land the same way in Danish as it did in English.
   > "The aim for translation is fidelity of tone, not just of words."
   >
   > — `goals-2026.md`

   > "A translated caption should land the same way in Danish as it did in English."

   > — `goals-2026.md`
